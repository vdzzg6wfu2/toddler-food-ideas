# 【专家谈科普】胆固醇高要不要紧，如何让胆固醇保持平衡？医生这样说

> 更新时间：2026-09-17 (UTC+8)

胆固醇是我们体中一种必要的物质，一般情况下，胆固醇的正常值会在0-5.2mmo/L(0-200mg/dl)这个范围之内，而超过这个范围就是高胆固醇了。

胆固醇过高带来的危害很多，例如会加速前列腺癌的增长速度，引发肾脏疾病；另外高胆固醇的男性中风几率也会增加。

应该如何控制胆固醇，高胆固醇人群的饮食有哪些禁忌？为什么有些人明明已经很忌口了依然胆固醇不稳定？今天，让**安徽医科大学第一附属医院内分泌代谢科副主任医师许敏**来为大家科普一下。

**胆固醇的概念**

**许敏介绍，胆固醇其实跟磷脂、油脂一样，都归属于脂类，是细胞膜、血浆蛋白的主要成分。**同时也是类固醇激素、胆汁酸以及维生素D的前体。胆固醇不溶于水，只有在与脂蛋白结合后，才能随血液在身体内运行。脂蛋白分为两种，分别是低密度脂蛋白和高密度脂蛋白。低密度脂蛋白将胆固醇运输至动脉，它的增多通常就会增加动脉硬化，心脑血管堵塞的风险，所以就被视为**“坏胆固醇”**。而高密度脂蛋白却是从动脉中移除胆固醇，通过肝脏作用排出体外，对身体有益，是**“好胆固醇”。**

**如何从体检表发现胆固醇的异常？哪些人群需要3-6月就要查一下血脂？**

**好胆固醇越高越好**

**坏胆固醇越低越好吗**

**胆固醇真的有好坏之分吗？坏的胆固醇是不是越低越好？**

许敏指出，“好胆固醇”的确是高点好，但也不能过高，那样总胆固醇也可能相应偏高，对健康不利。

“坏胆固醇”正常值应该低于3.4毫摩尔每升，有心血管疾病的患者则要控制在1.8毫摩尔每升~2.6毫摩尔每升以下。“坏胆固醇”指标也并非越低越好。低于正常值太多，可能意味着两个问题：

**一是严重营养不良，**

**二是合成功能障碍，比如严重肝病。**

如果胆固醇过低还伴消瘦，要排除肿瘤的可能。

**如何让胆固醇**

**维持在平衡状态**

**要想胆固醇水平维持在一个稳定状态，许敏建议平时需要做到以下几点：**

****

**一、控制胆固醇摄入量**。想要维持正常的代谢，首先控制从食物中摄取的胆固醇量，以减少代谢器官的负担。少吃精细的碳水化合物，如精米面等；控制饱和脂肪摄入，如零食中的椰子油、棕榈油等，还包括牛羊猪等禽肉；少吃植脂末，如速溶咖啡、饮料等。

**二、减少胆固醇吸收**。比如一些可溶性膳食纤维，包含燕麦、糙米、豆类等，能帮助减少胆固醇的吸收；

**三、保护肝脏。**胆固醇主要是在肝脏中转化为胆汁酸，因此，想要维持正常的胆固醇代谢，肝功能正常很重要。日常的伤肝行为，如：熬夜、抽烟、酗酒、乱吃药等都尽量避免。
