# 【健康贴士】你造神马是“急性短暂性精神障碍”吗？

> 更新时间：2026-09-16 (UTC+8)

近日，南京宝马肇事案延伸出的“急性短暂性精神障碍”引起网友热议。那么，“急性短暂性精神障碍”是否存在？它到底又是种什么病呢？

急性短暂性精神障碍是否存在？

 急性短暂性精神障碍(ATPD)虽然不为人熟知，但确实是存在的。对多数人而言，这是个陌生的概念，很容易简化成“精神病”，甚或嘲讽为“断片了”。有研究表明，在美国，急性短暂性精神病占所有首发精神病的9%。有的急性短暂性精神病人在发病前是有预兆的，比如刚刚经历过一次重大生活事件，或者长期失眠；当然也有一些病人发病是没有任何诱因的。 

什么是急性短暂性精神障碍？

 急性短暂性精神障碍(ATPD)是一种精神病性障碍，病症特点是起病急骤、病程较短，主要表现是片段幻觉、妄想等。它和以往的精神分裂症不太一样，主要是有一定的现实基础，也跟个性相关，例如环境当中某些不良因素可能会让一些性格不健全或有缺陷的人出现急性疾病，表现出一种急性错乱的状态。 

急性短暂性精神障碍如何判断？

 受到外界突然刺激后，每一个正常人或多或少都可能出现急性短暂性精神障碍症状，如抑郁、焦虑、血压增高、心率加快、面红耳赤或恐惧、面色苍白、出凉汗、四肢无力等，甚至出现敌对情绪，但大多数人可以在短时间内平缓自己的心态，少数人不能控制自己的情绪，甚至暴力伤人害己。

 由于这类精神障碍的起病急骤，恢复良好又无残留症状，在临床上所见不多，由于其发病病因至今尚未完全明确，目前对其判断可能会出现误诊。

急性短暂性精神障碍怎样防治？

1. 尽快脱离刺激源；

2. 可以做深呼吸、活动腰腿四肢，有助于调整心理状态；

3. 可以少量服用镇静药物以及抗精神病药，舒缓紧张、焦虑、惊恐状态；

4. 辅助做一些心理支持、心理疏导和心理治疗等。
